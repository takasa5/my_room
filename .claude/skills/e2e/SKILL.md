# E2E テスト

`index.html` を Chromium（`playwright-core`）で開いて操作し、ブラウザでしか確かめられないことを確かめる。
main へのマージがそのまま公開になるので、E2E は「公開されたページで、部屋が描けず小物も押せない」状態を止める最後の関門になる。

## 何を防ぐか

E2E で防ぐのは次の 2 つだけ。見た目の良し悪し、性能、使いやすさは扱わない。

* **できるはずのことができない**：部屋が描けない、小物を押してもパネルが開かない、パネルが閉じられない、画像やリンクが出ない
* **起きてはいけないことが起きる**：ページのエラー（`pageerror`、console の error）、スマホの幅で横にはみ出す、外部サービスが落ちたら画面ごと壊れる

## どこに足すか

上から順に当てはめ、最初に当てはまったところに足す。

1. **`data.js` / `filmarks.js` の形**（キーの有無、型、URL が https か、`scene.js` に同じ id の家具があるか）→ `scripts/check-data.js` に足す。E2E には足さない
2. **新しい外部サービスを使い始める**（画像の配信元、API、JSONP など）→ `e2e/smoke.e2e.js` の `routeExternal` に差し替えを足す。そのうえで、それを使うパネルの 1 本と「外部が全部落ちていても〜」の 1 本の両方で確かめる
3. **ブラウザでしか確かめられず、壊れると困るもの**（パネルの中身、押したときの動き、レイアウトの崩れ）→ `e2e/smoke.e2e.js` に 1 本足す
4. **どれでもない** → 足さない。たとえば次のもの
   * `scene.js` の絵柄、色、文字の選び方。ピクセルや文字列の比較はしない（少し変えるたびに壊れ、何も守らない）
   * アニメーションの時間や揺れ方
   * 既存の 1 本が同じ道を通っているもの（小物が 1 つ増えただけなら、「すべての小物とカードがある」が `data.js` の全項目を見ているので足さない）

分岐の網羅を E2E に持ち込まない。分岐が増えたら、その処理を関数に切り出して Node で試せる形にし、E2E は代表の 1 本にとどめる。

## 書き方

* **外へつながない**：`routeExternal` が 127.0.0.1 以外への通信をすべて横取りする。Google Fonts は空の CSS、ブクログは JSONP の `callback` を読んで偽の本を返し、画像は 1x1 の PNG を返す。それ以外は失敗させる。本物のサイトにつなぐテストは書かない（CI の結果が外部の状態で揺れる）
* **描き終わりを待つ**：`withPage` が `#room[data-ready='1']` を待ってからテストの中身を動かす。描画は上から少しずつ進むので、その前に `span[data-id]` を数えても全部はそろっていない
* **エラーは自動で見る**：`withPage` がページのエラーを集め、最後に空であることを確かめる。`offline: true` のときだけ、読み込み失敗のエラーは正しいものとして除く
* **期待値は `data.js` から読む**：タイトルやリンクを文字列でテストに書かず、`window.ROOM_DATA` / `window.FILMARKS` から取る。データを変えるたびにテストを直さなくてよいように
* **失敗したら画面を残す**：`withPage` が `e2e/.output/<名前>.png` に保存する（CI では artifact `e2e-screenshots`）

### 書いたら、壊して確かめる

実装の後に書く。書いたら、**該当するコードを壊して、そのテストが失敗すること**を確かめてから戻す。実装の今の動きをそのまま正解にしてしまうのを防ぐため。
「起きないこと」を確かめるテスト（エラーが出ない、はみ出さない）は、何もしなくても通ってしまうので特に注意する。

## 時間の予算

CI の `e2e` ジョブ全体で 3 分以内（今はインストール込みで 40 秒ほど、テストは 1 本 2 秒ほど）。1 本ごとにページを開き直して描き直すので、本数がそのまま時間になる。足す前に、既存の 1 本に確かめることを足せないかを考える。

## 実行

| コマンド | 中身 |
| --- | --- |
| `npm run e2e` | 全部（CI と同じ） |
| `node --test --test-name-pattern="本を押す" e2e/smoke.e2e.js` | 名前で絞って 1 本だけ（ディレクトリではなくファイルを渡す） |

初回は `npm ci` と `npx playwright-core install chromium` が必要。

## 落とし穴

* **閉じた `dialog` は見えない**：`#panel:not([open])` の表示を待つと、閉じた dialog は非表示なので永遠に終わらない。閉じたことは `waitForSelector("#panel[open]", { state: "detached" })` で待つ
* **小物の押し方**：`#room span[data-id="<id>"]` の最初の 1 つを押す。小物は同じ id の span に分かれているので、どれを押しても同じパネルが開く
* **画像の待ち方**：パネルの画像は開く前に先読みしているので、開いた時点でもう `<img>` がある。読み込みに失敗した画像は要素ごと消えるので、「あること」を確かめるときは差し替えが効いているかも疑う
* **スマホの幅**：幅 700px 未満では描く文字数（`COLS`）が変わり、別の道を通る。レイアウトに関わる変更は「スマホの幅でも〜」の 1 本でも確かめる
